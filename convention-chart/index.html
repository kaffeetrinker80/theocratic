How this tool works

A quick guide to the convention organization chart

Two separate things

The personnel master is your list of people (the contacts). Assignments only point to a person — so editing someone once updates every position they hold.

Personnel master (contacts)

  • Click Personnel: n at the top to jump straight to the contact list.
  • Use + Person to add someone, or the search box to find them. The list is sorted A–Z by last name.
  • Tick Regular Pioneer where it applies. Phone numbers link to WhatsApp; e-mails open your mail app.
  • Expand all / Collapse all at the top of this panel open or close every section — top-level tabs and nested ones — in one click.

Hierarchy & assignments

  • Open Edit data. Under Convention committee, each committee role (coordinator, program overseer, rooming overseer, …) has its own colour and its own Departments list — expand a role to assign its departments.
  • The colour and letter (a., b., c.) shown for each committee member also mark that department group on its print page, so it stays clear which department reports to which committee member.
  • Other overview sections (contract representative, convention chairman, …) are assigned the same way, independently of the coloured departments.
  • Every assignment field is a single search-and-pick box: click it to see everyone, or type a few letters to narrow it down, then click a match (or press Enter to take the top one).
  • Next to it, + creates a brand-new person and assigns them right there, and ✎ edits the currently assigned person — no detour through the personnel master needed.
  • The small i button on any row in the preview shows that person’s full stored details.

Personnel master

  • Click Personnel: n in the toolbar to open the contact table in its own window: search, sort by clicking a column header, click a row to edit, add or remove people.
  • Each person is stored once and can be assigned to any number of roles — editing them updates every assignment.
  • Congregation / group: mark a person as belonging to a group — the chart then shows e.g. “Munich-English (Group)”. If you change it for one person, the tool offers to change everyone else with the same congregation name too; for a new person it pre-selects the type that the others with that name already have.
  • Date of birth accepts a bare year (2001) or a full date (14.03.2001 or 2001-03-14).

Saving & sharing (JSON)

  • Import — one button; it auto-detects a roster file or a full backup.
  • Export personnel — the roster only (no assignments or settings). Safe to share.
  • Export backup — everything: settings, committee structure, departments and people. This is your complete save file. The file name carries the chart title and a time stamp, so several saves never overwrite each other.
  • Export CSV — a spreadsheet of all assignments (or one row per person) with the columns you choose.

Printing

  • Print / PDF prints one A4 landscape sheet per page; the cover sheet carries the title, the following sheets are colour-coded by committee member.
  • Compact print squeezes more rows onto each page.
  • Print with all details adds private e-mail, birth date, pioneer status and notes as a second line under each name.
  • Repeat title and column header on every page is off by default (a plain page, like the cover-only layout). Switch it on if you'd rather see the title and column names repeated on every sheet.
  • If a committee member's departments don't fit on one page, the tool automatically continues them on an extra page (marked “continued”) instead of cutting anything off.

Privacy: private e-mail, birth date, pioneer status and notes are never printed unless you switch on “Print with all details”. A full backup does contain this private data — keep that file to yourself.
