Cloud sync (Supabase)

All devices that open this page share one data record. Changes are uploaded automatically after a short pause and picked up by the other devices within about 20 seconds. No login required – anyone with the link can read and edit.

Each congregation gets its own record, derived from its name. This separates the data – protected by a 5-digit access code. The code is verified in the database, not in this page – without it the record cannot be read or written. The list of congregation names is visible to everyone; the data behind them is not.

💡 Tip: give this device a name (e.g. "Hall-PC") so everyone can see which device saved the latest changes.
