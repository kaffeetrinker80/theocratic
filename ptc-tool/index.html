PTC Tool – English Public Speakers (EU) · Quick guide for v2.3.2

This tool helps Public Talk Coordinators work with the English Public Speakers (EU) list faster and more comfortably. It imports the CSV export, searches speakers and congregations, saves local notes and memory, marks favorites, calculates distance from your home congregation when geo data is available, and prepares correction suggestions for Ronald.

01 Import and updates

Start with Import CSV. The tool reads congregation data, speaker names, contact details, circuits, meeting times, outlines, and optional geo fields.

When you get an updated CSV, just import it again. Speaker memory such as favorites, notes, last invited, and last used is matched again when the speaker is recognized.

Use Export JSON from time to time so your personal work is backed up.

02 Search and filters

The first toolbar row is for the normal list work: main search, outline filter, country, circuit, meeting day, and speaker role.

The main search looks through speaker name, congregation, city, country, circuit, phone, email, outline number, outline title, and saved local notes. Outline titles and status information come exclusively from outline-data.json; if that file is unavailable, outline numbers stay usable but titles and statuses are not guessed.

03 Distance tools

The second toolbar row handles distance only:

  • Distance mode – air-line or estimated drive × 1.25
  • Max distance – for example within 50 / 100 / 150 / 200 km
  • Sort – by name or by distance

These controls work when the imported CSV contains usable geo coordinates for the congregations.

04 Home congregation

Open a congregation and click Set as home congregation. After that the top button Home congregation jumps back to it, distances are calculated from that point, and result cards can show nearby congregations and speakers.

If no home congregation is set, the distance tools stay available but cannot calculate meaningful values yet.

05 Speaker and congregation view

Speaker View is best when you already know the brother or the outline you need.

Congregation View is best when you want to review a whole congregation first, including the PTC and all available speakers in one place. There you can click a speaker directly in the speaker list and open his details on the right side.

06 Back to congregation

When you open a speaker directly from a congregation, the tool remembers that congregation. In the selected speaker area you will see ← Back to congregation directly above the highlighted speaker box, so you can review several brothers from the same congregation without searching again.

07 Outline search

The outline filter works two ways: by number, for example 76, or by words from the title, for example family, hope, or hospitality. That makes it easy to find brothers even when you only remember the subject but not the exact outline number.

The ≡ button in the outline field opens the outline directory: every outline from outline-data.json with its title, status, retiring date, and how many speakers in the current list offer it. Search it by number, title, or note, narrow it by status, or tick Only with speakers to hide outlines nobody covers. Clicking an entry filters the speaker list by that outline.

Where an outline carries a note, an i marker appears. The note is shortened in the row and shown in full when you hover or tap the marker, so a long note never pushes the list apart. Outline chips on the result cards and in the speaker details are clickable too and open the directory at that outline.

08 Printing and PDF

The Print button in the header opens a dialog with a live preview of the exact sheet that will be printed. Choose what goes on it — the current filter results, favorites only, just the selected congregation, or the whole list — and pick one of three layouts: grouped by congregation, a flat speaker list, or grouped by outline number, which answers "who can give talk #45" at a glance.

Switch on Outline titles to print the title next to every number in very small type. It costs little space and turns the sheet into something you can work from without looking anything up. Retiring and withdrawn outlines are marked, either with the status in brackets or with an asterisk when only numbers are printed.

Print to PDF through your browser's print dialog. Turning off the browser's own headers and footers there gives a clean sheet. New page per congregation is useful when you want to file or send one sheet per congregation.

09 Favorites and speaker memory

For each speaker you can save favorite status, last invited, last used, notes, and manual PTC assistant entries for congregations.

This is local browser memory and is also included in the JSON export. Use Export Notes + Assistants if you only want to back up your personal additions. It helps with brothers you invite often, brothers you want to keep in mind, or avoiding the same speaker too frequently.

10 Contacts and shortcuts

The tool turns saved data into practical shortcuts: e-mail links, phone and WhatsApp links where possible, the hall address to Google Maps, and PTC contact export as .vcf. This is meant to reduce copy and paste work.

11 Corrections

If something in the list is outdated or incomplete, use the correction section on a speaker or congregation. You can describe what is wrong, suggest the correction, and send a prepared WhatsApp or email message.

The page Help Us Improve also collects likely field issues in one place for easier review.

12 A practical routine

  1. Import the newest CSV.
  2. Set or confirm your home congregation.
  3. Use search and the outline filter.
  4. Switch to congregation view to compare several brothers from one congregation.
  5. Use distance filters if you want nearby options first.
  6. Keep notes and memory updated.
  7. Export JSON as backup, or Export Notes + Assistants for only your personal additions.

13 One reminder

The tool makes the list much easier to work with, but the results still depend on the quality of the imported data. Careful review, timely updates, and useful corrections remain very valuable.
