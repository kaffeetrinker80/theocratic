This tool helps Public Talk Coordinators work with the English Public Speakers (EU) list faster and more comfortably. It imports the speaker list as CSV or as PTC Organizer JSON, searches speakers and congregations, saves local notes and memory, marks favorites, calculates distance from your home congregation when geo data is available, and prepares correction suggestions for Ronald.

01 Import and updates

One button, Import, handles every supported file. The tool looks at the content rather than the file name, so it recognizes:

  • the speaker list CSV — flat or structured/geocoded,
  • the PTC Organizer master JSON — the export of the organizer tool,
  • a tool backup JSON — full backup or notes-only, as written by the export buttons.

CSV and master JSON produce the same data state: congregations, speakers, contacts, outlines, meeting times and coordinates end up identical, because both routes build their keys from congregation and speaker names, never from internal ids. You can therefore switch between the two formats at any time without losing anything.

The master JSON additionally carries information the CSV has no columns for: Zoom availability, a maximum travel distance, notes from the source data, and the distinction between a congregation and a group. Where present, these appear as extra chips on the speaker card. Source notes stay read-only and separate from your personal notes; importing an updated master never writes them into your local note field. It also skips entries that should no longer be used — dissolved congregations, deleted and inactive speakers — and reports each of them under Import warnings.

When you get an updated file, just import it again. Speaker memory such as favorites, notes, last invited, and last used is matched again when the speaker is recognized, and your home congregation is re-selected by name.

Use Export JSON from time to time so your personal work is backed up.

02 Search and filters

The first toolbar row is for the normal list work: main search, outline filter, country, circuit, meeting day, and speaker role.

The main search looks through speaker name, congregation, city, country, circuit, phone, email, outline number, outline title, and saved local notes. Outline titles and status information come exclusively from outline-data.json; if that file is unavailable, outline numbers stay usable but titles and statuses are not guessed.

03 Distance tools

The second toolbar row handles distance only:

  • Distance mode – air-line or estimated drive × 1.25
  • Max distance – for example within 50 / 100 / 150 / 200 km
  • Sort – by name or by distance

These controls work when the imported CSV contains usable geo coordinates for the congregations.

04 Home congregation

Open a congregation and click Set as home congregation. After that the top button Home congregation jumps back to it, distances are calculated from that point, and result cards can show nearby congregations and speakers.

If no home congregation is set, the distance tools stay available but cannot calculate meaningful values yet.

05 Speaker and congregation view

Since v2.4 the two sides have a clear division of labour: the right panel always shows congregation data — address, meeting time, distance, PTC contact, PTC assistant, the speaker list, and the congregation correction form. Everything that belongs to one brother opens in the speaker card, a modal window on top.

Speaker View is best when you already know the brother or the outline you need. Clicking a result opens his speaker card and at the same time loads his congregation into the right panel, so both are ready.

Congregation View is best when you want to review a whole congregation first. Click any brother in the speaker list to open his card without losing the congregation you are looking at.

06 The speaker card

The speaker card holds the role and distance chips, phone and e-mail links, all outlines, the speaker memory (favorite, last invited, last used, notes), and the correction form for that brother. Close it with Close, the Esc key, or a click on the dark background.

Because the congregation stays visible behind the card, you can go through several brothers of the same congregation one after another — no scrolling back and forth. Show congregation → at the bottom of the card closes it and switches the list to Congregation View for that hall.

Clicking an outline chip inside the card opens the outline directory on top of it. Choosing an outline there filters the result list and closes the speaker card, so you immediately see who else offers that talk.

07 Outline search

The outline filter works two ways: by number, for example 76, or by words from the title, for example family, hope, or hospitality. That makes it easy to find brothers even when you only remember the subject but not the exact outline number.

Sort: Outline orders the current results by the lowest available outline number. With no outline filter active this naturally starts at 1, 2, 3 …; with an outline search active, the matching outline is used as the sort key.

The ≡ button in the outline field opens the outline directory: every outline from outline-data.json with its title, status, retiring date, and how many speakers in the current list offer it. Search it by number, title, or note, narrow it by status, or tick Only with speakers to hide outlines nobody covers. Clicking an entry filters the speaker list by that outline.

Where an outline carries a note, an i marker appears. The note is shortened in the row and shown in full when you hover or tap the marker, so a long note never pushes the list apart. Outline chips on the result cards and in the speaker details are clickable too and open the directory at that outline.

08 Printing and PDF

The Print button in the header opens a dialog with a live preview of the exact sheet that will be printed. Choose what goes on it — the current filter results, favorites only, just the selected congregation, or the whole list — and pick one of three layouts: grouped by congregation, a flat speaker list, or grouped by outline number, which answers "who can give talk #45" at a glance.

Switch on Outline titles to print the title next to every number in very small type. It costs little space and turns the sheet into something you can work from without looking anything up. Retiring and withdrawn outlines are marked, either with the status in brackets or with an asterisk when only numbers are printed.

Print to PDF through your browser's print dialog. Turning off the browser's own headers and footers there gives a clean sheet. New page per congregation is useful when you want to file or send one sheet per congregation.

09 Favorites and speaker memory

For each speaker you can save favorite status, last invited, last used and personal notes. Congregation and PTC notes are part of the same local memory.

Open Backup and choose Personal Notes only to export only this personal memory. PTC Assistant contacts are source data and are intentionally not part of the personal-notes file; they come from the CSV or PTC Organizer Master.

10 Contacts and shortcuts

The tool turns saved data into practical shortcuts: e-mail links, phone and WhatsApp links where possible, the hall address to Google Maps, and PTC contact export as .vcf. This is meant to reduce copy and paste work.

11 Corrections

If something in the list is outdated or incomplete, use the correction section on a speaker or congregation. You can describe what is wrong, suggest the correction, and send a prepared WhatsApp or email message.

The page Help Us Improve also collects likely field issues in one place for easier review.

12 A practical routine

  1. Import the newest CSV.
  2. Set or confirm your home congregation.
  3. Use search and the outline filter.
  4. Switch to congregation view to compare several brothers from one congregation.
  5. Use distance filters if you want nearby options first.
  6. Keep notes and memory updated.
  7. Export JSON as backup, or Export Notes + Assistants for only your personal additions.

13 Screen edge / taskbar

If a bar sits permanently on top of your browser window — most often a Windows taskbar set to auto-hide — it covers the lowest strip of the page. No web page can measure such a bar, so the tool simply keeps that strip free: the modal footers, the scroll-to-top button, and the sticky result list all stay above it.

Default is 56 pixels. Set it to 0 if nothing overlaps your window, or raise it if your bar is taller. The value is stored in this browser.

pixels

Only applies to desktop-sized windows. On phones and tablets the tool uses the device safe area instead.

14 One reminder

The tool makes the list much easier to work with, but the results still depend on the quality of the imported data. Careful review, timely updates, and useful corrections remain very valuable.
